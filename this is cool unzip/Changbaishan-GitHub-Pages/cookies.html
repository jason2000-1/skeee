Cookie policy

Last updated 5 October 2026

The guide itself does not set browser cookies. Its banner controls local storage: small records kept in this browser. It adds no analytics, advertising or cross-site tracking scripts.

Expired records are removed when the guide next checks storage. The records are not sent to the organiser by the guide. Browser settings may prevent storage or delete it sooner.

Choosing and changing settings

“Reject optional” leaves browsing available without saving trip selections across visits. “Allow preferences” saves those selections on this device. Neither scrolling nor silence grants optional consent. Open at any time, turn preferences off and save, or select “Reject optional”, to remove saved selections. The footer offers the same control on every policy page and the main guide.

The checkbox is off by default. If browser storage is blocked, controls continue to work, but the decision cannot be remembered between pages. Clearing browser site data resets the decision.

Hosting and linked websites

When published on GitHub Pages, GitHub processes hosting information, including visitor IP addresses for security. This banner controls only the guide’s browser storage; it does not control hosting logs or the technologies of other websites. See the GitHub Privacy Statement. Following an external link takes visitors to that website’s own privacy and cookie settings.
