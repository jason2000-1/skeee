THE SMALL PRINT

Privacy policy

Last updated 5 October 2026

Snow Days is a personal trip-planning guide. It has no booking form, newsletter, advertising trackers or analytics scripts added by the trip organiser.

What the guide stores

After a cookie-banner choice, the guide stores that choice in this browser for up to 180 days. Only when “Allow preferences” is selected does it also save the last selected itinerary day and destination tab. This information remains in this browser; the guide does not send it to the organiser or use it to identify visitors.

Without optional consent, tab choices work for the current page only. Declining optional storage does not prevent reading the guide. If browser storage is unavailable, a choice lasts only for that page.

Hosting and access

This downloadable edition is prepared for GitHub Pages. When published there, GitHub logs visitor IP addresses for security purposes. Hosting data is handled under the GitHub Privacy Statement. The guide’s cookie settings control only its own browser storage, not GitHub’s hosting logs or services. Opening the files locally does not use GitHub hosting.

Images and external links

Guide code, styles and photographs are served as local site assets. There are no embedded maps, external font requests or embedded social feeds added by the guide. Source and venue links lead to other websites when selected; those services have their own privacy practices. Photo credits identify the sources and do not imply that every image carries an open reuse licence.

Choices, retention and deletion

Use to change the decision at any time. Rejecting optional storage removes the saved trip preferences. The consent choice expires 180 days after the latest explicit choice; optional preferences expire with it and are removed when the guide next checks storage. Clearing this site’s browser data deletes both records. This guide does not sell personal information or use it for advertising.

Questions or corrections

Contact the trip organiser through the channel where this guide was shared for questions about guide content or privacy. For GitHub hosting or account data, use GitHub’s privacy contact options. Do not enter passport numbers, payment details or booking credentials into this guide; it has no facility to receive them.

Changes to this policy

This page describes the current implementation. If the guide’s data practices change, update this policy and request any necessary new preference choice before enabling new optional storage.
